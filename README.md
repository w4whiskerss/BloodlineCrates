# BloodlineCrates

`BloodlineCrates` is a Paper `1.21.11` crate plugin with RNG crates, selectable crates, virtual and physical keys, timed key rewards, internal GUIs, analytics, PlaceholderAPI support, and reloadable YAML-driven data.

## Build

```bash
mvn package
```

The compiled jar is written to `target/BloodlineCrates-1.0.0-SNAPSHOT.jar`.

## Current Scope

- RNG and selectable crate flow
- Internal preview and selection GUIs
- In-game editor shell with crate/key management
- Virtual and physical keys
- Timed key rewards
- YAML storage with optional MySQL-backed player profiles
- Opening effects, pity system, cooldowns, analytics, and audit logs
- PlaceholderAPI expansion and public Bukkit events
